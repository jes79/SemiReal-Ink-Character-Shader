# 1차시. 쉐이더 랩 둘러보기와 A/B 비교

| 항목 | 내용 |
|---|---|
| 수업 시간 | 180분 (시연 25 · 개념 45 · 쉬는 시간 10 · 실습 70 · 정리·과제 20 · 도입 10) |
| 난이도 | ★☆☆ (처음 만나는 날) |
| 시작 저장 지점 | `main` → 실습 중간에 `shader-lab-v1` |
| 쓰는 랩 탭 | **비교** (쉐이더 탭 카드·맵·보기 디버그는 짧게 맛보기, 나머지 탭은 이름만 훑기) |

## 학습 목표

1. 쉐이더·머티리얼·텍스처가 각각 무엇이고 어떻게 이어지는지 말할 수 있다.
2. 쉐이더 랩의 A/B 비교(와이프·나란히·A만·B만)를 써서 두 화면의 차이를 찾을 수 있다.
3. 쉐이더 파일의 `Properties` 블록과 머티리얼 인스펙터 칸이 1:1로 이어진다는 것을 확인한다.

## 시작 저장 지점

처음 복제는 [README의 받는 법](README.md#3-저장-지점-받는-법)을 따릅니다. 오늘은 두 지점을 차례로 엽니다.

```bash
# ① 처음 예제 (시연 앞부분)
git switch main
git lfs pull

# ② 쉐이더 랩 (시연 뒷부분 + 실습) — Unity를 닫고 실행
git switch -c lesson01 shader-lab-v1

```

### A. `main` — 처음 공개한 예제 (8분)

1. `Assets/CharacterShaderTest/Scenes/CharacterShaderTest.unity`를 열고 ▶ 플레이.
2. 왼쪽 위 **조작 패널 (H)** 을 보여 준다. 이것은 IMGUI(코드로 매 프레임 그리는 옛 방식 UI)다.
3. **와이프(1)** 상태에서 가운데 흰 선을 끌어 "원본 (URP Lit)"과 "새 쉐이더"를 비교한다.
4. **나란히(2)**, **원본만(3)**, **새 쉐이더만(4)**, `Tab`(원본 ↔ 새 쉐이더 빠르게 전환)을 차례로 누른다.
5. `M`(재질 판별 보기), `O`(먹 아웃라인), `P`(후처리)를 눌러 "버튼 하나로 화면이 이렇게 바뀐다"를 보여 준다.

![원본과 새 쉐이더 와이프 비교](../images/overview_wipe.png)

### B. `shader-lab-v1` — 쉐이더 랩 (12분)

6. Unity를 닫고 `shader-lab-v1`로 바꾼 뒤 다시 열어 플레이.

10. **쉐이더** 탭 → 스타일 카드 **리얼 / 세미리얼 / 스타일라이즈드**를 하나씩 눌러 B가 바뀌는 것을 보여 준다.

12. **애니메이션**·**커스텀** 탭은 v1에서 비어 있다("이 캐릭터에는 아직 …"). v2에서 채워진다고 말한다.

## 개념 설명

### 1. 용어 다섯 개

| 용어 | 한 줄 풀이 | 이 프로젝트에서 |
|---|---|---|
| 렌더 파이프라인 | 3D 장면을 화면 그림으로 바꾸는 순서·규칙 묶음 | URP 17.6 (Forward+) |
| 쉐이더 (Shader) | 픽셀 하나하나의 색을 계산하는 GPU 프로그램 | `Shaders/SemiRealInk.shader` (이름 `ShaderTest/SemiRealInk`) |
| 머티리얼 (Material) | 쉐이더 + 그 쉐이더에 넣을 값(텍스처·색·숫자)을 담은 에셋 | `Materials/FinalPlayer_SemiRealInk/*.mat` |
| 텍스처 (Texture) | 모델 표면에 붙이는 그림 또는 데이터 | `Textures/FinalPlayer/` |
| URP Lit | Unity가 기본으로 주는 물리 기반 쉐이더 | A 쪽 "원본"이 이것 |

[그림: 모델(메쉬) ← 머티리얼(쉐이더 + 값) ← 텍스처. 화살표로 "렌더러가 머티리얼을 쓰고, 머티리얼이 쉐이더와 텍스처를 쓴다"]

### 2. 쉐이더 파일의 큰 구조

`SemiRealInk.shader`는 크게 세 덩어리입니다.

| 덩어리 | 줄 | 하는 일 |
|---|---|---|
| `Properties { … }` | 15–133 | 머티리얼 인스펙터에 보일 칸 목록 |
| `HLSLINCLUDE … ENDHLSL` | 144–257 | 모든 패스가 같이 쓰는 값·함수 |
| `Pass { … }` 다섯 개 | 262 이후 | 실제로 그리는 단계 |

> **패스(Pass)**: 같은 물체를 한 번 그리는 단계. 쉐이더 하나가 여러 번 나눠 그릴 수 있다.

| 패스 이름 | 찾을 글자 | 하는 일 |
|---|---|---|
| `ForwardLit` | `Name "ForwardLit"` | 본체 색 (빛·재질) |
| `InkOutline` | `Name "InkOutline"` | 먹 아웃라인 (4차시) |
| `ShadowCaster` | `Name "ShadowCaster"` | 그림자 드리우기 |
| `DepthOnly` / `DepthNormals` | `Name "Depth` | 깊이·노멀 (SSAO 같은 화면 효과용) |

**Properties 한 줄 읽는 법** (17–20행):

```hlsl
[Header(Surface)]
[MainTexture] _BaseMap ("Base Map", 2D) = "white" {}
[MainColor] _BaseColor ("Base Color", Color) = (1, 1, 1, 1)
[ToggleUI] _UseBaseMap ("Use Base Map", Float) = 1
```

| 부분 | 뜻 |
|---|---|
| `[Header(Surface)]` | 인스펙터에 굵은 제목 "Surface" |
| `_BaseMap` | 코드에서 부르는 이름 (밑줄로 시작) |
| `"Base Map"` | 인스펙터에 보이는 이름 |
| `2D` / `Color` / `Float` / `Range(0, 1)` | 칸 종류 |
| `= 1` | 기본값 |
| `[ToggleUI]` | 숫자 0/1을 체크박스로 보여 줌 |

### 3. A/B 비교는 어떻게 만들었나

[그림: 같은 자리에 겹친 캐릭터 두 개(A는 레이어 ShaderCompare_Original, B는 ShaderCompare_New). 메인 카메라는 A만, 자식 카메라(Compare Camera (B))는 B만 찍음. 와이프 모드에서는 B 화면을 렌더 텍스처에 그려 UI가 오른쪽만 덮음]

| 재료 | 설명 | 파일 |
|---|---|---|
| 캐릭터 두 개 | `Character A (FinalPlayer)`, `Character B (FinalPlayer)`를 **같은 자리에 겹쳐** 둔다 (v2에서는 이름이 `Character A`, `Character B`) | 장면 |
| 레이어 두 개 | `ShaderCompare_Original`(A), `ShaderCompare_New`(B) | `CompareView.cs` |
| 카메라 두 대 | `Main Camera`(A만 찍음) + 자식 `Compare Camera (B)`(B만 찍음) | `CompareView.cs` |
| 렌더 텍스처 | 와이프·B만 보기에서 B 화면을 전체 크기로 따로 그려 둔 그림 | `CompareView.GetCompareTexture()` |
| 덮개 | UI가 렌더 텍스처의 **오른쪽 부분만** 화면에 덮는다 | `ShaderLabUI.UpdateCompareOverlay()` |

> **레이어(Layer)**: 오브젝트에 붙이는 분류 번호. 카메라의 `Culling Mask`로 "이 레이어만 찍기"를 할 수 있다.
> **렌더 텍스처(Render Texture)**: 카메라가 화면 대신 그림을 그려 넣는 텍스처.

와이프에서 B를 전체 크기로 그리는 까닭: 비네트(가장자리 어둡게)·필름 그레인 같은 후처리가 **양쪽에 똑같이** 걸리게 하려고. 나란히 보기는 카메라마다 화면 반쪽 크기로 그리므로 후처리가 반쪽마다 따로 걸린다(README 알려진 한계).

### 4. 랩 코드의 역할 나누기

| 파일 | 역할 | 한 줄 |
|---|---|---|
| `ShaderLabController.cs` | 상태 관리 | "지금 A·B 스타일, 스위치, 환경…" 을 들고 있고 바꾸는 함수를 가짐 |
| `ShaderLabUI.cs` | 화면(패널) | 탭 내용을 만들고 버튼을 Controller 함수에 연결 |
| `LabCharacter.cs` | 캐릭터 하나 | 원본/새 쉐이더 머티리얼을 기억하고 바꿔 끼움 |
| `StylePreset.cs` | 스타일 에셋 | 리얼·세미리얼·스타일라이즈드 값 묶음 |
| `CompareView.cs` | 비교 화면 | 카메라 두 대·렌더 텍스처 |
| `Editor/SemiRealInkTestSetup.cs` | 장면 만들기 메뉴 | **Tools → Shader Test → Build Test Scene** |

**중요한 규칙 — 머티리얼 복사본**: `LabCharacter`는 플레이할 때 새 쉐이더 머티리얼을 **복사**해서 씁니다(이름 끝에 `(Lab)`). 그래서 랩에서 무엇을 눌러도 `.mat` 파일은 바뀌지 않습니다.

```csharp
// LabCharacter.cs — Initialize() 안 (찾을 글자: "(Lab)")
copies[i] = new Material(authored) { name = authored.name + " (Lab)" };
```

## 정리

- 화면 = 메쉬 + 머티리얼(쉐이더 + 값) + 빛 + 후처리.
- 쉐이더 파일 = `Properties`(인스펙터 칸) + 공용 함수 + `Pass` 여러 개.
- A/B 비교 = 같은 자리 캐릭터 2개 + 레이어 2개 + 카메라 2대 + 렌더 텍스처 덮개.
- 플레이 중 랩에서 바꾼 값은 **머티리얼 복사본**에만 걸린다 → `.mat` 파일은 안전.
- 디버그 보기는 장면 전체(전역), 스타일은 랩 캐릭터에만.

## 과제

**과제 1. A/B 비교 캡처 3장** — 같은 시점에서 비교 조합 3개를 캡처하고 차이를 한 줄씩 쓴다.
(예: A 원본 / B 리얼, A 리얼 / B 세미리얼, A 세미리얼 / B 스타일라이즈드)

**과제 2. 랩 구조도** — `ShaderLabUI → ShaderLabController → LabCharacter → 머티리얼(복사본)` 흐름을 손그림이나 도형으로 그린다. 각 상자에 "하는 일" 한 줄.

| 제출물 | 채점 기준 | 배점 |
|---|---|---|
| 캡처 3장 (PNG) | 이름표(A·B 스타일)가 화면에 보인다 | 30 |
| 차이 설명 3줄 | 명암·외곽선·반사 등 **눈에 보이는 차이**를 구체적으로 적었다 | 30 |
| 구조도 1장 | 상자 4개 이상 + 화살표 방향이 맞다 | 30 |

## 확인 질문

1. 플레이 중 랩에서 스타일을 바꿨는데 `Materials/FinalPlayer_SemiRealInk` 안 `.mat` 파일은 바뀌지 않는다. 왜일까?
   - **정답**: `LabCharacter`가 플레이 시작 때 머티리얼 **복사본**(`(Lab)`)을 만들어 그것만 바꾸기 때문.
2. 와이프 모드에서 B 화면을 화면 전체 크기로 따로 그리는 이유는?
   - **정답**: 비네트·필름 그레인 같은 후처리가 A·B 양쪽에 똑같이 걸리게 하려고.
3. `[ToggleUI] _UseBaseMap ("Use Base Map", Float) = 1` 에서 `"Use Base Map"` 과 `_UseBaseMap` 은 각각 어디에 쓰이는가?
   - **정답**: `"Use Base Map"`은 인스펙터에 보이는 이름, `_UseBaseMap`은 쉐이더·C# 코드에서 부르는 이름.

## 자주 막히는 곳

| 증상 | 원인 | 해결 |
|---|---|---|
| 캐릭터가 분홍색·흰색, 텍스처가 없음 | LFS 파일을 못 받음 (ZIP으로 받았거나 `git lfs install` 안 함) | `git lfs install` → `git lfs pull` |
| 패널 글자가 네모(□) | 한글 글꼴이 없음 | 맑은 고딕 등 설치. 콘솔에 "한글 글꼴을 찾지 못했습니다" 경고가 뜸 |
| `git switch` 가 "would be overwritten" 오류 | 고친 파일이 남아 있음 | `git stash` 또는 commit 후 다시 |
| `git switch -c lesson01 shader-lab-v1` 에서 태그를 못 찾음 | 태그를 안 받음 | `git fetch --all --tags` |
| 콘솔에 "레이어 … 가 없습니다" | 레이어가 지워짐 | **Tools → Shader Test → Build Test Scene** |
| 마우스로 캐릭터가 안 돌아감 | 마우스가 패널 위에 있음 / 게임 창에 초점 없음 | 게임 창을 한 번 클릭하고 패널 밖에서 드래그 |
| 숫자 키가 안 먹음 | Game 창이 아닌 다른 창에 초점 | Game 창 클릭 |
